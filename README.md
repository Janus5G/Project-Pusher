# Project Pusher

## Start

1. Installer Node.js 22.12 eller nyere og Git.
2. Kor `npm install` i denne mappe, hvis installationsscriptet blev kort med `-SkipInstall`.
3. Kor `start.cmd` eller `npm start`.

## GitHub

Opret et fine-grained personal access token med adgang kun til det repository,
du vil pushe til. Tokenet bruges kun til den enkelte push og gemmes ikke.

Eksisterende projektfiler og en eksisterende, anderledes Git-remote overskrives
ikke automatisk.
